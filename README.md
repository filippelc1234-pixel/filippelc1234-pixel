## Jak go ustawić (2 minuty, w przeglądarce)

GitHub ma sekretną funkcję: repo o nazwie **takiej samej jak Twój login** pokazuje swój README na profilu.

**1.** Na github.com → **New** (zielony przycisk)
**2.** Repository name: wpisz dokładnie **`filippelc1234-pixel`**
→ GitHub pokaże ✨ *„You found a secret!"* — to znaczy, że robisz to dobrze
**3.** Zaznacz **Public** + **Add a README**
**4.** Kliknij **Create repository**
**5.** Otwórz `README.md` → **ołówek (Edit)** → usuń wszystko → **wklej zawartość mojego pliku** → **Commit changes**

Gotowe — wejdź na swój profil i zobacz. 🔥
